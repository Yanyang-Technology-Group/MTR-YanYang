## English

This project is a **fork** of [Minecraft Transit Railway (MTR)](https://github.com/Minecraft-Transit-Railway/Minecraft-Transit-Railway).

### Optimization Notes

Version 4.0.0 is a complete rewrite. The vehicle simulation code has been separated from the Minecraft instance, greatly reducing lag on Minecraft servers.

Major optimizations in 4.0.0 include:

- Client-side FPS improvements
- Server-side TPS improvements
- Significantly reduced server lag (vehicle simulation code separated from the Minecraft instance)
